# Deploy MedLounge Live (Free)

## Option A – GitHub Pages (recommended)

1. Create a free GitHub account if you don’t have one.
2. Create a new repository named e.g. `medlounge`.
3. Upload all files from this folder (`index.html`, `css/`, `js/`, `manifest.json`, `sw.js`).
4. Go to **Settings → Pages**.
5. Under “Source” choose **Deploy from a branch** → `main` → `/ (root)`.
6. Wait 1–2 minutes. Your site will be at:
   `https://YOUR_USERNAME.github.io/medlounge/`

## Option B – Netlify Drop (fastest)

1. Go to https://app.netlify.com/drop
2. Drag the entire `medlounge` folder onto the page.
3. You get a live link instantly (you can later claim it with a free account).

## Option C – VS Code + Live Server (local only)

1. Install the **Live Server** extension in VS Code.
2. Right-click `index.html` → **Open with Live Server**.

---

After deploying, anyone can open the link on phone or computer.
On mobile they can also **Add to Home Screen** for the app-like PWA experience.
